## 摘要

本报告用"学术注意力"与"产业化节奏"的背离定位瓶颈与颠覆，两级判定：

- **瓶颈在子方向级判**：提及量大、份额停滞（≤1.05，±5% 噪声带）、产业没撤（专利 ≥0.95）。
  问题真实存在，学术侧却推不动。
- **颠覆在词条级判**：起点是算法判定的热点词条（emerging / potential；少数已是 core 的大盘
  词条只作支撑，不单独成方向），再逐条做**跨源校验**——专利增速（两年比率，**年化后**）
  是否跟得上论文份额同比。

按这个判据，33 个子方向里 **4 个同时满足瓶颈的三条门槛**（长时储能、电力电子化稳定性、
氢能、电池与储能材料），**2 个曾被列为瓶颈但不满足判据**（新能源消纳、碳捕集——后者按互斥规则归入伪前沿）。
颠覆方向 **6 个**，其中 2 条的跨源校验不过（方向 3 有一半词条、方向 5 整条），已标为观察项。
另有 **4 类"看起来热、其实不是前沿"**。

> 一句话：**电力系统从"以同步机为主体"转向"以电力电子为主体"的卡点，不在器件本身，而在
> 长时储能的经济性、电力电子系统的稳定性理论、氢的储—运、电池/储能材料的成本与供应链四处；
> 最可能改变格局的是构网型控制、电-氢-碳耦合与市场机制。**

> **外部交叉验证**：第 5 节用公开资料（维基百科条目 + arXiv 预印本）对 11 条判断逐条核对，
> **9 条强/一致、1 条部分一致、1 条部分一致且需降级**（AI 闭环的证据最弱）。与公开信息
> 冲突处单独列出，未做掩盖。

## 一、方法与判据

### 1.1 三级分析单元，各自回答不同问题

| 层级 | 数量 | 回答的问题 | 判据所在 |
|---|---|---|---|
| 词条 | 1,811 | 某个具体技术在起势还是退潮？ | `potential` / `emerging` / `core` 门槛（算法） |
| 子方向 | 33 | 这个方向整体"推得动"吗？ | `subtopic` 门槛（本报告 §1.3） |
| 议题 | 由词条组人工圈定 | 跨子方向的组合判断是否成立？ | 专家判断，逐条给证据 |

**为什么瓶颈必须看子方向、颠覆必须看词条**：偏离"技术前沿"的证据在子方向层最稳（单个词条的
噪声会被平均掉），而新方向的特征恰恰是"只在窄词条上先冒头"——若放到子方向层，它会被同方向
的成熟词条稀释掉。把两者压在同一层，就会出现"同一个证据既证明瓶颈、又证明颠覆"的矛盾。

### 1.2 指标定义

| 概念 | 操作定义 | 为什么这样定义 |
|---|---|---|
| 学术注意力（词条） | 近一年文档频率 DF = 命中篇数 ÷ 同期语料篇数 | 分母是同期语料，排除了语料本身增长 |
| 份额同比（yoy） | `df_recent / df_prev` | **已经除掉了语料增长**：近一年语料同比 1.275，若用原始命中数相比，所有方向都会"白涨 27.5%" |
| 子方向份额同比 | (Σ近两年命中 +0.5) ÷ 语料，再除以上一年的同一比值 | 与词条级同构；分子求和、分母同一套语料 |
| 子方向稳健性列 | 成员词条 yoy 的中位数、25 分位、同比 <1.0 的占比 | 判断"整体在退"是普遍现象还是少数大词条拖动 |
| 产业节奏 | 专利同比 =(2024+2025 +1)/(2022+2023 +1) | 专利比论文更接近工程投入；**两年比率，与一年份额同比比较时必须年化** |
| 制度节奏 | 政策同比（2024–2026 vs 2021–2023） | 政策语料仅 6,621 条，只作诊断，不作判据 |

> 子方向指标已固化为 `data/subtopic_report.csv`（口径见 [METHOD §4](METHOD.md)），
> 本报告所有"子方向份额/增速"都能对到该表的某一列，不再有人工挑词条得到的数字。

### 1.3 判据（全部可复算，门槛在 `config/subtopic_rules.json`）

| 类别 | 门槛 | 一句话解释 |
|---|---|---|
| **瓶颈** | 子方向三年提及量 ≥3,000 ∧ 份额同比 ≤1.05 ∧ 专利同比 ≥0.95 | 讨论量很大、份额停滞、产业没撤 |
| **颠覆（候选）** | 起点：词条级 `emerging` 或 `potential`（算法判定）；强度：跨源校验 `patent_growth ≥ max(1.25, yoy²)` 或政策侧达标 | 学术侧已起势或跨源领先；校验不过的降为观察项 |
| **伪前沿·学术热产业冷** | 子方向规模 ∧ 份额同比 ≥1.00 ∧ 专利同比 <0.95 | 论文在涨、产业在退 |
| **伪前沿·双退** | 子方向规模 ∧ 份额同比 <1.00 ∧ 专利同比 <0.95 | 两侧同时收缩 |

**三处刻意的设计选择（v1 的错都在这里）**

1. **±5% 噪声带，双向对称**。停滞是 `≤1.05`，产业没撤是 `≥0.95`。用 1.00 硬阈值会让
   1.010 与 1.000 这 1% 之差决定成败——那是抽样噪声，不是信号。
2. **专利增速必须年化后再比**。专利是"近两年 ÷ 前两年"的两年比率，份额同比是一年比率。
   代码里的 `potential` 门槛用 `yoy²` 做年化对齐；v1 用"专利 ≥ 份额×1.2"的线性系数，
   等于拿两年增速直接比一年增速，天然把东西判成"颠覆"。
3. **子方向只归一类，性质改判必须留痕**。互斥优先级 `瓶颈 > 学术热产业冷 > 双退`；
   算法看不见的性质（例如"已在工程优化阶段"）只能写在 `config/subtopic_review.json`
   并附理由，报告正文必须引用该理由。非技术类子方向（表征与测试、战略规划、地区实践）
   在该文件里排除，不参与技术判定。

## 二、关键瓶颈（4 个，全部通过判据）

### 瓶颈 1｜长时储能：路线分散，经济性与寿命卡住

| 证据（子方向 1.2） | 数值 |
|---|---|
| 三年提及量 | 727,147（规模门槛 ✓） |
| 份额同比 | **0.944**（停滞 ✓）；成员中位数 0.947，62% 的成员词条在退 |
| 专利同比 | **0.96**（88,623 / 92,068，产业没撤 ✓） |
| 季度份额斜率 | −0.004 |

| 关键路线（词条） | DF（近一年） | 份额同比 | 专利同比 |
|---|---:|---:|---:|
| 液流电池 | 0.114% | 1.005 | 1.29 |
| 压缩空气储能 | 0.100% | 1.127 | 1.85 |
| 抽水蓄能电站 | **0.016%** | 1.011 | 1.66 |
| 容量衰减 | 0.196% | 1.145 | 1.71 |
| 锂离子电池（背景） | 3.047% | 0.924 | 0.82 |

**判断**：锂电体系（DF 3% 量级）已经把"储能"变成领域背景语，且份额在退（0.924）；而
长时储能的四条路线全都停在 **0.1% 量级**，没有任何一条在学术上取得主导地位。这是
**注意力分布**的证据，不是可行性判断——它说明"路线之争尚未收敛"，而不是"某条路线不可行"。

值得注意的是：抽水蓄能电站的专利 341 件、政策 170 条，看起来"双高"，但**政策同比只有 0.83**
（204→170），制度侧其实在收缩。把计数当增速读，会得出相反结论。

**突破条件**：4 小时以上系统的度电成本进入火电调峰区间；容量电价/容量市场落地；
长周期（>15 年）寿命数据积累。

### 瓶颈 2｜电力电子化系统：器件大盘在退，稳定性问题在进

| 证据（子方向 6.2） | 数值 |
|---|---|
| 三年提及量 | 194,564（规模 ✓） |
| 份额同比 | **1.024**（停滞 ✓，+2.4%）；成员中位数 1.010，48% 的成员在退 |
| 专利同比 | **1.02**（42,182 / 41,440，产业没撤 ✓） |
| 季度份额斜率 | −0.004 |

| 分层（词条） | DF | 份额同比 | 专利同比 |
|---|---:|---:|---:|
| 器件大盘：直流-直流变换器 | 1.972% | 1.073 | **0.84** |
| 器件大盘：变流器 | 1.739% | 0.963 | 1.06 |
| 器件大盘：二极管 / 电容器 | 0.796% / 0.837% | **0.806 / 0.863** | 0.90 / 0.89 |
| 控制/惯量：系统惯量 | 0.471% | **1.324** | 1.71 |
| 控制/惯量：碳化硅 | 0.769% | 1.156 | 1.50 |
| 控制/惯量：宽禁带半导体 | 0.131% | 1.300 | 1.08 |
| 单点补丁：虚拟惯量 | 0.340% | **0.995**（在退） | 1.77 |

**判断**：子方向整体"分毫不动"（+2.4%），但内部发生了**结构置换**——二极管（−19%）、
电容器（−14%）这些"器件本体"的份额在退，直流-直流变换器论文在涨（1.073）而专利在退
（0.84），而系统惯量、宽禁带、碳化硅在涨。
该子方向另有 **28 条专利先行词条**（频率稳定性 2.27×、电磁干扰 1.46×、双有源桥变换器 1.44×、
软开关 1.55×、一次/二次调频、PI/PID 控制等），几乎全是控制、拓扑与损耗类。

这正是"旧理论不够用、新范式未统一"的形态：**低惯量、宽频振荡、故障电流特性这些新问题，
传统稳定分析方法给不出答案**，而单点补丁式研究（虚拟惯量 0.995、局部放电 0.977）已经饱和。
子方向总量不动，是"涨的部分被退的部分抵掉"，不是"没人研究"。

**突破条件**：构网型控制从"设备级并网"上升到"系统级稳定性定义"；保护定值与故障电流的
新标准；仿真与硬件在环的可信度。

### 瓶颈 3｜氢能：制氢已工程化，储—运仍是断层

| 证据（子方向 7.6） | 数值 |
|---|---|
| 三年提及量 | 220,591（规模 ✓） |
| 份额同比 | **0.925**（停滞 ✓）；成员中位数 0.931，64% 的成员在退 |
| 专利同比 | **1.23**（2,836 / 2,308，产业在进 ✓） |
| 季度份额斜率 | −0.005 |

| 分层（词条） | DF | 份额同比 | 专利（近两年） |
|---|---:|---:|---:|
| 制氢（已在工程化） | 1.769% | 0.975 | 866 件 / 1.61× |
| 电解水 | 0.527% | 0.995 | 255 件 / 1.30× |
| 燃料电池（在退） | 1.193% | **0.850** | 760 件 / 0.93× |
| 储运：固态储氢 | 0.058% | 1.751 | 28 件 / 2.07× |
| 储运：氢能基础设施 | 0.053% | 1.901 | 0 件 |
| 储运：氢脆 | 0.048% | 2.115 | 2 件 |

**判断**：子方向整体在退（0.925），但退的是"燃料电池 + 电催化"这一层（燃料电池 0.850、
电催化剂 0.827），而**制氢/电解水已经停止增长却维持巨大量级**（制氢 DF 1.77%、866 件专利），
说明它进入了工程化阶段，不再是研究前沿。

真正的断层在**"储—运"**：氢脆、固态储氢、氢能基础设施三条线斜率都很陡，但 DF 全部
不到 0.06%——方向被识别了，还没有成为主流方案。产业侧已经改走"把氢变成分子"的路径
（绿氨、绿色甲醇专利爆发，见方向 2），这是绕开储运瓶颈的现实做法。

**突破条件**：储氢密度与成本、管道掺氢标准、氢脆机理的工程可预测性；绿色分子的终端市场。

### 瓶颈 4｜电池与储能材料：学术热度回落，产业投入未撤

| 证据（子方向 9.1） | 数值 |
|---|---|
| 三年提及量 | 107,038（规模 ✓） |
| 份额同比 | **0.872**（回落 ✓，−12.8%）；季度斜率 −0.021 |
| 专利同比 | **1.07**（212 / 198，产业没撤 ✓） |
| 政策同比（仅诊断） | 0.86（49 / 57） |

**判断**：9.1 是四个瓶颈里唯一"论文侧在退、专利侧仍在进"的。专利从 198 件增至 212 件，
说明材料侧并没有像 9.2 半导体材料、9.3 催化基础那样"双退"，而是从"发现新材料"转向
**降本、量产、供应链与工程验证**；学术关注度回落，不等于产业停止投入。政策同比 0.86 只作
诊断，不参与判定。

这与旧版把它归入"双退"的读法不同：**份额下跌 + 专利仍在涨**，按 v2 判据是瓶颈，不是伪前沿。
需要单独说明的是，9.1 的专利基数（198→212）远小于 1.2/6.2/7.6，结论对单件专利更敏感；
它作为"材料成本与供应链"的瓶颈信号，强度低于前三个。

**突破条件**：材料成本与供应链韧性、制造良率与规模一致性、长循环寿命的工程数据。

### 2.4 未通过判据、因此**不列为瓶颈**的两个议题

**（1）新能源消纳不构成瓶颈（份额 1.303，在涨）。**
"弃风弃光"词条斜率 +0.220（全库第 4）、近一年 143 篇；"可再生能源并网" DF 0.344%、
份额同比 1.415；子方向 1.3 份额同比 1.303、专利 1.15、政策 1.07——三项全在涨。这是
"正在被大量研究、且产业在同步投入"的领域，不是"学术推不动"的领域。

但它仍有一个值得记下的结论：消纳是系统级问题，没有单一技术可指认，所以论文里表现为
一堆小词条各自增长。卡点在**"源—网—荷—储"协同调度与输电通道**，而不是某个设备。
这个判断的证据是外部案例（见 5.2 第 2 条），不是本报告的份额数据。

**（2）碳捕集按互斥规则归入伪前沿（份额 1.053 / 专利 0.87）。**
论文在涨（碳捕集词条 1.188、直接空气捕集 1.138、碳封存监测 2.754），专利在退（子方向
2,537 / 2,914 = 0.87）——这是"成本与能耗未解、产业不敢投"的典型信号，属第四节
"学术热、产业冷"，不重复计入瓶颈。

## 三、潜在颠覆性方向（6 个，词条组 + 跨源校验）

起点是算法判定的热点词条（`terms_report.csv` 的 `hotspot_class` = emerging / potential；
少数已是 core 的大盘词条只作支撑行），强度用**跨源校验**衡量：**专利同比 ≥ max(1.25,
份额同比²)**（年化对齐）或政策侧达标。下表"校验"列直接取自 `pass_potential`，

统计：**强一致 7 条、一致 2 条（合计 9）、部分一致 1 条、部分一致且需降级 1 条。**

### 5.3 三处需要修正的地方

1. **AI 闭环方向要降级。** 六个词条里有三个没通过专利门槛（数字孪生 2.64× 低于 6.83、
   异常检测不达标、网络安全靠政策过关）。更准确的表述是：**"AI 正在大规模进入电网的离线
   分析与预测，是否进入闭环仍未验证"**。本报告把它标为"观察项"。
2. **电-氢-碳的"爆发"要打折。** 绿色甲醇 8× 的基数是 7 件 vs 0 件，+1 平滑下几乎没有
   统计意义。建议改用项目数据库（而非专利）二次核实。
3. **构网型的边界要说清。** 公开文献指出 GFM 的能力上限受直流侧与拓扑约束
   （arXiv:2504.20367），不是纯控制问题——"软件升级即构网"可能高估了存量设备的改造空间。

### 5.4 用 arXiv 独立计数复核（不依赖搜索服务）

arXiv 的语料与本研究使用的 OpenAlex 能源子集**不重合**（arXiv 偏物理/CS/工程预印本），
因此它的计数是一次独立检验。按提交日期分两段（2021–2022 / 2023–2026）检索：

| 检索式 | 2021–2022 | 2023–2026 | 倍数 | 与本研究信号的对比 |
|---|---:|---:|---:|---|
| `all:"grid-forming"` | 72 | 291 | **4.0×** | 本研究：构网型逆变器份额 1.429、斜率 +0.131 → 方向一致，arXiv 更强 |
| `all:"carbon capture"` | 37 | 163 | **4.4×** | 本研究：5.1 份额 1.053（微涨）→ 方向一致，幅度差很大 |
| `all:"long-duration energy storage"` | 2 | 18 | 9.0× | 本研究：液流/压缩空气 DF 仅 0.1% → 一致：**倍数再高，总量也只有 20 篇** |
| `all:"hydrogen embrittlement"` | 19 | 62 | **3.3×** | 本研究：氢脆份额 2.115 → 方向与量级都接近 |

**这个对照暴露了一个方法学问题，值得记下来**：arXiv 给的是**绝对数量倍数**（4 倍左右），
本研究给的是**份额倍数**（0.9–2.6）。差异不是矛盾，而是分母不同——2021–2026 年 arXiv 本身
在快速扩张，绝对量增长里包含"预印本习惯普及"和"领域整体膨胀"。**份额口径扣掉了这部分，
所以更保守**。凡两份证据不一致时，应优先相信份额口径的方向，而不是绝对量的倍数。

同时它印证了两个"瓶颈型"判断：长时储能即便增长 9 倍，全库仅 20 篇，说明**尚未形成独立的
技术文献族群**；氢脆稳定增长且机理仍在争论（见上一节 2022 年论文的表述），**属于"投入在
增加但结论未收敛"的典型瓶颈**。

**限制**：arXiv 检索是对标题/摘要全文的布尔匹配，不做同义词扩展；`grid-forming`、
`carbon capture` 这类带连字符/多词表述会漏掉变体，因此上述数字只能看**趋势与量级**，
不能当作精确的论文数。

### 5.5 数据与公开信息一致指向的结论

两条独立证据链（本研究 154.9 万篇论文/53.8 万件专利/6,621 条政策的份额信号；公开百科与预印本
索引的叙事）在**同一处交汇**：

> **瓶颈不在"发电"，在"谁建立电压与频率""能量怎么存得住""材料怎么降本""灵活性如何变现"。**

## 六、结论：四个最该盯的交叉点

1. **构网型控制 × 系统级稳定性标准**：窄词条（DF 0.19%）上斜率 +0.131、专利 6.16×、
   子方向政策 1.35×，是唯一"技术侧刚起势、制度侧已动手"的组合，直接决定高比例电力电子
   系统的可行性。
2. **电-氢-碳耦合 × 绿色燃料市场**：唯一能绕开长时储能物理约束的路径，专利增速最高，
   但基数极小、受国际规则约束——看项目落地，不看专利倍数。
3. **AI 闭环 × 电网安全认证**（**观察项**）：潜力最大也最容易被高估。六个词条里三个没通过
   专利门槛，外部核对也没找到闭环运行的公开案例，现阶段只能确认"离线分析与预测已规模化"。
4. **电池/储能材料 × 成本与供应链**：9.1 份额 0.872（学术热度回落）、专利 1.07（产业未撤），
   是"论文退、产业进"的降本与良率瓶颈；它不像前三个那样有清晰的技术路线，但对规模化速度
   的约束同样直接。

**如果只能给一个判断**：未来 5 年电网能源领域的技术分水岭，不在"发多少电"，而在
**"谁来建立电压和频率"**——构网型控制是目前唯一有产业共识的答案，但它受硬件约束，
不是纯软件问题。

## 附 A：数据口径与可复现性

- 词条级指标取自 `data/terms_report.csv`（上游流水线产出，本仓库只读）；**子方向级指标取自
  `data/subtopic_report.csv`**，可由 `grid-bottleneck subtopics` 从 `data/` 复算，
  且与本仓库自带快照**逐字节一致**（口径见 [METHOD §4](METHOD.md)）。
- 份额 = 命中篇数 ÷ 同期语料篇数（近一年 423,464 篇、上一年 332,096 篇、近三年 1,043,978 篇）。
- **份额同比 `yoy` = 近一年份额 ÷ 上一年份额，语料增长已被约掉**。因此判据全部与 **1.0**
  比较：`yoy < 1.0` 即相对萎缩。（v1 附录写"凡份额同比 < 1.275 均为相对萎缩"，是把
  已归一化的比率又比了一次语料增速，属明确错误，已删。）
- 语料同比 1.275 只用于一处：子方向聚合时把 Σ命中 除以语料分母（见 METHOD §4）。
- 季度斜率为近三年 12 个季度 log(份额) 的 OLS 斜率。
- 专利增速 =(2024+2025 专利数 +1) / (2022+2023 专利数 +1)；政策增速同理（2024–2026 vs
  2021–2023）。
- 专利语料 2021–2026 共 538,066 件（按公开号去重）；词条级专利计数也按 `publication_number`
  首次出现去重（v2.1 修正；此前聚合表/分表重复行被逐条计入，已重算）；2026 仅约 1–5 月、收录口径与
  2021–2025 不同，**只入覆盖与逐年计数，不参与增速判定**（增速仍用 2024–2025 / 2022–2023）。
- 子方向判据门槛在 `config/subtopic_rules.json`；人工复核（非技术子方向
  排除、性质改判）在 `config/subtopic_review.json`，改判必须写理由。
- 词条级三类热点的完整名单在上游仓库（词条级流水线）；本仓库方法与门槛见 [METHOD.md](METHOD.md)，
