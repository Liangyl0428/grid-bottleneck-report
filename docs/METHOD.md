# 方法与判据

本文档与代码一一对应：凡出现数值处，都可从 `data/` + `config/` 复算
（`grid-bottleneck subtopics`）。文档与代码不一致视为 bug。

```
src/grid_bottleneck/windows.py    分析窗口（冻结）
src/grid_bottleneck/subtopic.py   子方向聚合与互斥归类
src/grid_bottleneck/verify.py     报告数字对账
config/subtopic_rules.json        子方向判定门槛
config/subtopic_review.json       人工复核（排除 / 性质改判，必须写理由）
data/*.csv                        派生数据快照（词条级指标由上游流水线产出）
```

## 1. 窗口（冻结）

| 名称 | 区间 | 季度数 |
|---|---|---|
| history | 2021-07-01 .. 2026-06-30 | 20 |
| core（近三年） | 2023-07-01 .. 2026-06-30 | 12 |
| recent（近一年） | 2025-07-01 .. 2026-06-30 | 4 |
| prev（上一年） | 2024-07-01 .. 2025-06-30 | 4 |

语料：近一年 423,464 篇 / 上一年 332,096 篇，**同比 1.275**；近三年 1,043,978 篇。
改窗口等于换结论，必须同步本文件与 `windows.py`。

## 2. 计数规则（上游执行，本仓库沿用其结果）

| 规则 | 做法 | 为什么 |
|---|---|---|
| 计数单位 | 每篇文档对每个词条至多计 1 次 | 一个词条平均 2.45 个变体，按模式累加会让同一篇论文被重复计入（总体虚高 7.2%） |
| 父子词条 | 最长匹配抑制 | 词典中 240 个中文名是其它词条的子串（石墨 ⊂ 石墨烯） |
| 英文写法 | 分隔符归一（`-`/`_`/`/` → 空格）+ 复数变体 | 语料 99% 不是中文，召回依赖英文写法 |
| 短缩略语 | 全大写、无空格、2–6 字符走大小写敏感匹配 | `CO` 全小写匹配会把 `Co`（钴）、`co-doped` 全部计入（该词条虚增 58%） |
| 季度口径 | year-only 占位（1 月 1 日）按该年实际出现季度均摊 | 占位率 2022 年 10.4% → 2026 年 25.0%，且全堆在 Q1，会伪造"Q1 尖峰 + 近期加速" |
| 专利去重 | 按公开号全局去重 | 同一专利同时出现在聚合表与 IPC 分表 |

## 3. 指标

- `hits_3y / hits_recent / hits_prev`：窗口内命中文档数（含季度均摊权重）。
- `df_recent`：份额 = 命中篇数 ÷ 同窗口语料篇数。
- **`yoy = df_recent / df_prev`**：份额同比，**语料增长已被约掉**。因此判据一律与 **1.0**
  比较；拿它再去比 1.275 是二次归一化，会得出"所有方向都在萎缩"的错误结论。
- `slope`：12 个季度 `log(份额)` 的 OLS 斜率；有效季度 < 8 时为 0。
- `patent_growth = (2024+2025 专利 + 1) / (2022+2023 专利 + 1)`；`policy_growth` 同理
  （2024–2026 vs 2021–2023）。**两年比率**。
- `hotspot_class`：词条级三类判定（core / emerging / potential），由上游流水线按
  `config` 门槛给出；本仓库只读快照，不重算。其 `potential` 门槛含年化对齐：
  `patent_growth ≥ max(1.25, yoy²)` 或 `policies_recent ≥ 10 ∧ policy_growth ≥ 1.2`。

## 4. 子方向聚合（本仓库的核心）

上层分析用子方向回答"这个方向推得动吗"，这需要逐条可复算的聚合。

**口径（硬要求：论文侧与专利侧都用求和，不允许一侧求和、另一侧取中位数）**

| 指标 | 定义 | 说明 |
|---|---|---|
| `hits_3y` | 成员词条三年命中数之和 | 等于子方向的"总提及量"，**不是**去重后的文档数（成员词条常在同一篇论文里共现）。只用于量级门槛。 |
| `share_recent` / `share_prev` | (Σ命中 + 0.5) ÷ 同窗口语料篇数 | 与词条级 `df` 同构 |
| `share_yoy` | `share_recent / share_prev` | **已扣掉语料增长**（近一年语料同比 1.275） |
| `share_yoy_median` / `share_yoy_p25` / `declining_share` | 成员词条 `yoy` 的中位数 / 25 分位 / 同比 <1.0 的占比 | **稳健性列，不参与判定**。加总值与中位数背离 >0.10 时，正文必须说明由哪些词条驱动 |
| `slope` | 12 个季度 Σ命中 ÷ 季度语料 的 log OLS 斜率 | 与词条级同算法 |
| `patent_growth` / `policy_growth` | (Σ近两年 +1) ÷ (Σ前两年 +1) | 与词条级同算法 |

## 5. 判据

| 类别 | 门槛 | 为什么 |
|---|---|---|
| 规模 | `hits_3y ≥ 3,000` | 低于此值时季度斜率与份额同比都不可靠 |
| **瓶颈** | 规模 ∧ `share_yoy ≤ 1.05` ∧ `patent_growth ≥ 0.95` | 讨论量很大、份额停滞（±5% 噪声带）、产业没撤（允许 5% 萎缩，与停滞带对称） |
| **伪前沿·学术热产业冷** | 规模 ∧ `share_yoy ≥ 1.00` ∧ `patent_growth < 0.95` | 论文在涨、产业在退 |
| **伪前沿·双退** | 规模 ∧ `share_yoy < 1.00` ∧ `patent_growth < 0.95` | 两侧同时收缩 |

**为什么停滞门槛只有一条**：`share_yoy_median ≤ 1.0` 这类"多数成员在退"的条件看似更稳，
实际会让 1.010 与 1.000 的 1% 之差决定成败。中位数与"在退占比"作为稳健性列输出，
由正文在两者背离时解释，不进入判定。

**为什么产业侧只认专利**：政策语料仅 7,070 条，单个子方向近两年常不足 100 条；
用政策增速替代专利，会把"半导体部门政策"这类域外信号误算成电网产业信号。

**互斥与人工复核**

1. 一个子方向只进一类，优先级 `瓶颈 > 学术热产业冷 > 双退`；`class_primary` 是唯一归类。
2. **颠覆方向不在这一层判**：新方向往往是窄词条（DF < 0.3%），子方向级会把它们和成熟成员
   混在一起。颠覆按词条级 `hotspot_class` + 跨源校验判。因此"某子方向是瓶颈"与"该子方向内
   某个词条是新兴方向"可以并存，但必须在报告的归属表里写明**对象边界**（例：子方向 1.2 归
   瓶颈"长时储能"，其内部钠离子/固态电池三个词条归方向"锂电替代体系"）。
3. 性质类改判（如"已在工程优化阶段"）只能写在 `config/subtopic_review.json`，且必须带理由；
   非技术类子方向（表征与测试、战略规划、地区实践）在该文件里排除，不参与技术判定。
   报告正文必须引用该理由，不许口头改判。

## 6. 复现

```bash
grid-bottleneck subtopics --out /tmp/x.csv   # 复算（与 data/subtopic_report.csv 逐字节一致）
grid-bottleneck verify                       # 报告数字对账
pytest                                       # 口径 / 互斥 / 快照 / 对账
```

## 7. 已知限制

1. **热度 ≠ 技术突破**。统计只说明"在文献/专利/政策里被讨论得多"，不说明技术成熟度或
   产业价值。词典含"表征与测试方法"子方向，质谱、XRD 这类词条进候选是词典设计使然。
2. **语料不是严格的能源全库**。175 万篇中只有 34% 能匹配到能源锚点词，域外噪声靠 DF
   阈值压制，挡不住全部。
3. **子方向提及量是求和，含共现重复**。它只能作量级门槛，不能读作"子方向有多少篇论文"。
4. **专利与政策覆盖期不同**。政策 7,070 条（2013–2026），专利 2021–2025。
5. **专利有 18 个月公开滞后**，近两年的专利数不完整；这是所有"产业化节奏"指标的共同上限。
6. **人工复核可复现但带主观性**。规则写在 config，换一个人复核会得到略有差异的名单。
7. **本仓库不能重算词条级指标**（缺原始语料）。若上游重扫语料，`data/` 需要整体更新，
   且报告里的数字可能变化——所以每个数字都配了对账工具。
