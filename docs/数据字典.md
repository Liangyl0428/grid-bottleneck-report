# 数据字典

`data/` 下 8 个文件，全部是**派生统计**，不含论文/专利/政策原文。

---

## `terms_report.csv`（1,811 行）

词条级指标与热点判定。一行一个技术词条。

| 列 | 含义 |
|---|---|
| `term` / `term_en` | 中文官方名 / 英文官方名（`term` 在本快照内唯一，可作连接键） |
| `subtopic` | 所属子方向（`编号 名称`） |
| `hotspot_class` | `core` / `emerging` / `potential`；未入选为空 |
| `excluded_reason` | 未入选原因：`domain_umbrella`（领域通用语）/ `cross_domain` / `below_gate` |
| `in_shortlist` | 是否进入对外短名单（发布配额，**不影响判定**） |
| `pass_core` / `pass_emerging` / `pass_potential` | 三类门槛的原始结果（1/0，可审计） |
| `is_background` / `is_cross_domain` / `low_anchor_coverage` | 排除检查标记 |
| `hits_3y` / `hits_recent` / `hits_prev` / `hits_base` | 各窗口命中文档数（含季度均摊权重） |
| `df_recent` / `df_prev` / `df_3y` | 各窗口份额（文档频率） |
| `yoy` | 份额同比 = `df_recent / df_prev`，**语料增长已约掉** |
| `vs_3y` | 近一年份额 ÷ 近三年份额 |
| `slope` | 12 个季度 log(份额) 的 OLS 斜率 |
| `stability` | 12 个季度里命中数 ≥ 自身中位数一半的季度占比 |
| `energy_lift` / `energy_context` | 能源锚点 lift 诊断列（默认不参与判定） |
| `citation_mean` | 命中论文的篇均被引 |
| `patents_recent` / `patents_base` | 近两年（2024–2025）/ 前两年（2022–2023）专利数 |
| `patent_growth` | `(patents_recent+1)/(patents_base+1)`，**两年比率** |
| `policies_recent` / `policies_base` | 政策数（2024–2026 / 2021–2023；政策侧只作诊断） |
| `policy_growth` | `(policies_recent+1)/(policies_base+1)` |
| `core_score` / `emerging_score` / `potential_score` | 类别内排序分（不参与入选） |
| `rank_core` / `rank_emerging` / `rank_potential` | 类别内名次 |

## `subtopic_report.csv`（33 行）★

子方向级聚合与判据。**可由 `grid-bottleneck subtopics` 从本目录其他文件复算，
且保证逐字节一致**。

| 列 | 含义 |
|---|---|
| `code` / `subtopic` | 子方向编号（如 `6.2`）/ 全名 |
| `n_terms` / `n_terms_hits` | 成员词条数 / 其中三年有命中的词条数 |
| `hits_3y` | 成员词条三年命中数之和（= 提及量，含共现重复，只作规模门槛） |
| `df_3y_sum` | `hits_3y` ÷ 近三年语料（求和口径的份额，**不是覆盖率**） |
| `hits_recent` / `hits_prev` | 近一年 / 上一年命中数之和 |
| `share_recent` / `share_prev` | (Σ命中 + 0.5) ÷ 同窗口语料 |
| `share_yoy` | `share_recent / share_prev`，**已扣掉语料增长（1.275）** |
| `share_yoy_median` / `share_yoy_p25` | 成员词条 yoy 的中位数 / 25 分位（稳健性列，不参与判定） |
| `declining_share` | 成员词条中 yoy < 1.0 的占比 |
| `slope` | 12 个季度 Σ命中 ÷ 季度语料 的 log OLS 斜率 |
| `patents_recent` / `patents_base` | Σ近两年 / Σ前两年专利数 |
| `patent_growth` | `(Σ近两年+1)/(Σ前两年+1)` |
| `patent_growth_annualized` | `sqrt(patent_growth)`，用于与一年份额同比对齐 |
| `policies_recent` / `policies_base` / `policy_growth` | 政策侧同构（只作诊断） |
| `pass_scale` | `hits_3y ≥ 3000` |
| `pass_stagnant` | `share_yoy ≤ 1.05` |
| `pass_industry_hold` | `patent_growth ≥ 0.95` |
| `pass_small_base` | `df_3y_sum ≤ 0.003`（基数仍小） |
| `pass_academic_hot` | `share_yoy ≥ 1.00 且 patent_growth < 0.95` |
| `class_primary` | 唯一归类：`bottleneck` / `academic_hot_industry_cold` / `both_declining` / `mature_industry` / 空 |
| `class_note` | 人工复核说明（排除理由或改判理由） |

## `papers_by_quarter.csv`（词条 × 季度，约 3.6 万行）

| 列 | 含义 |
|---|---|
| `term_id` | `子方向编号\|词条名` 形式的内部键 |
| `term` / `term_en` / `subtopic` | 词条与归属 |
| `quarter` | `2021Q3` .. `2026Q2` |
| `papers` | 该季度命中文档数（float，year-only 文档按季度均摊，故有小数） |
| `papers_anch` | 其中同时命中能源锚点的文档数（诊断用） |

## `patents_by_year.csv` / `policies_by_year.csv`

| 列 | 含义 |
|---|---|
| `term_id` / `term` / `term_en` / `subtopic` | 同上 |
| `year` | 专利 2021–2026（2026 仅约 1–5 月）；政策 1993–2026（2000 年后 6,620） |
| `patents` / `policies` | 该年度命中数 |

## `corpus_totals.csv`（20 行）

| 列 | 含义 |
|---|---|
| `quarter` | 季度 |
| `docs` | 该季度语料文档量 —— **所有份额的分母** |
| `docs_anchored` / `anchored_share` | 能匹配到能源锚点的文档量与占比（诊断用） |

## `dict_snapshot.csv`

| 列 | 含义 |
|---|---|
| `term_id` / `term` / `term_en` | 同上 |
| `aliases` | 别称/简称（匹配时使用） |
| `subtopic` | 归属子方向 |

## `run_meta.json`

上游运行元信息：版本、构建时间、扫描文档数、词条数、计数规则开关。
（内部语料路径已移除。）
